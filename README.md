# Лабораторна робота №1
## Моделювання електронного документа
**Дисципліна:** «Системи електронного документообігу»  
**Варіант:** 5 (Рахунок / Invoice)

---

### Опис проєкту
Проєкт реалізує модель електронного документа (рахунку) у форматі JSON. Програма на Python автоматично сканує каталог `documents/`, перевіряє наявність обов'язкових загальних і специфічних полів, контролює унікальність ідентифікаторів (`id`) та виводить результати валідації.

### Структура проєкту
```text
lab1_document_model/
│
├── main.py             # Головний скрипт валідації та читання
└── documents/          # Каталог із JSON-файлами документів
    ├── doc_001.json
    ├── doc_002.json
    ├── doc_003.json
    └── doc_004.json

    Команда **`python3 main.py`** запускає інтерпретатор Python для виконання програми з файлу `main.py`.
