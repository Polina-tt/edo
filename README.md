# Лабораторна робота №2. Життєвий цикл електронного документа та версійність

## Загальна інформація
* **Дисципліна:** «Системи електронного документообігу»
* **Варіант:** №1 — Заява студента (`student_application`)
* **Мова програмування:** Python 3

---

## Мета роботи
Реалізація моделі життєвого циклу електронного документа, побудова моделі станів (FSM) з перевіркою дозволених і заборонених переходів, ведення хронологічної історії змін із мітками часу, а також налаштування контролю версійності при редагуванні змістовних полів із подальшим збереженням стану у форматі JSON.

---

## Структура проєкту
Проєкт складається з двох основних файлів:
1. **`document.json`** — файл сховища даних, який містить поточний стан документа, атрибути, версію, зміст та історію переходів.
2. **`main.py`** — основний скрипт, що реалізує клас `ElectronicDocument`, логіку перевірки станів, управління версіями та сценарії тестування.
