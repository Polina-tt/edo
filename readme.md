# Лабораторна робота №3
## Зберігання електронних документів: файлова система та SQLite
**Дисципліна:** «Системи електронного документообігу»  
**Варіант 4:** Договори  

---

### 1. Мета роботи
Реалізація гібридної моделі зберігання електронних документів у Системі електронного документообігу (СЕД), де:
* **Метадані** (номер договору, контрагент, сума, статус, автор, версія, шлях до файла) зберігаються в реляційній базі даних **SQLite**.
* **Самі файли документів** (текстовий вміст) зберігаються у файловій системі в каталозі `storage/`.

---

### 2. Структура проєкту
```text
lab3_document_storage/
│
├── main.py          # Основний скрипт програми (логіка БД та файлів)
├── documents.db     # Файл бази даних SQLite (створюється автоматично)
└── storage/         # Каталог для фізичних файлів документів
    ├── doc-001.txt
    ├── doc-002.txt
    ├── doc-003.txt
    ├── doc-004.txt
    └── doc-005.txt
